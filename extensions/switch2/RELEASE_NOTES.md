# Nintendo Switch 2 1.0.4

## 中文

- 社区机种包新增 Nintendo Switch 2。可从内置存储或 TF 卡的 `.nup` 直接启动已在 Banana Native 中 Prepare 的游戏。
- 包内含随主题着色的机种 Logo、彩色像素机种图、日版红色包装盒和游戏卡模型，以及三语安装、Prepare、存档迁移和同步说明。
- 在 AYANEO Pocket FIT Elite 上以 RetroMao 1.2.5 和 Banana Native 0.3.50 验证了两种存储、停止游戏后返回、未 Prepare 提示，以及共享存档目录迁移和首次同步。每台设备需自行授权目录并选择同步来源。

## English

- Adds Nintendo Switch 2 to Community platforms. Boot prepared `.nup` games from internal storage or a TF card with Banana Native.
- Includes a theme-tinted platform logo, a color pixel icon, red Japanese-style case and card models, and trilingual instructions for setup, Prepare, save migration and sync.
- Tested both storage locations, return after Stop Game, the missing-Prepare prompt, shared-folder save migration and first sync on an AYANEO Pocket FIT Elite with RetroMao 1.2.5 and Banana Native 0.3.50. Set folder access and the sync provider on each device.

## 日本語

- コミュニティの機種に Nintendo Switch 2 を追加しました。内部ストレージまたは microSD カードにある Prepare 済みの `.nup` を Banana Native で起動できます。
- テーマ色に連動するロゴ、カラーのピクセルアイコン、日本向けの赤いケースとゲームカードのモデル、導入・Prepare・セーブ移行と同期の三言語手順を同梱しています。
- AYANEO Pocket FIT Elite の RetroMao 1.2.5 と Banana Native 0.3.50 で両方のストレージからの起動、終了後の復帰、未 Prepare 時の表示、共有フォルダーへのセーブ移行と初回同期を確認しました。各端末でフォルダーの許可と同期サービスの選択が必要です。
