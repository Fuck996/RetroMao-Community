# Azahar Plus 1.0.1

## 中文

首次商店发行：通过 Azahar Plus 启动 Nintendo 3DS 游戏，支持共存版与替换版。最低宿主版本修正为 0.9.138，排除未包含该接口的 0.9.136／0.9.137 独立验收包；四语卡片简介缩短。启用、更新、禁用、卸载、URI 授权及启动门禁自动检查已通过。没有脚本、页面、网络权限或模拟器安装包。真实设备进入游戏仍待验收。

## English

First store release: launch Nintendo 3DS games with either Azahar Plus Android variant. The minimum host is corrected to 0.9.138 because the isolated 0.9.136/0.9.137 acceptance builds did not include this interface. All four card descriptions are shortened. Automated lifecycle, URI-grant and launch checks passed. No scripts, pages, network permissions or emulator APK are included. Actual device gameplay remains unverified.

## 日本語

初回ストア公開版です。Azahar Plus の共存版・置換版で Nintendo 3DS を起動します。独立した 0.9.136／0.9.137 検証ビルドには本機能が含まれないため、必要なホストを 0.9.138 に修正しました。四言語のカード説明も短縮しています。有効化、更新、無効化、削除、URI 権限と起動の自動検証は通過しました。スクリプト、ページ、ネットワーク権限、エミュレーター APK は含みません。実機のゲーム起動は未検証です。
