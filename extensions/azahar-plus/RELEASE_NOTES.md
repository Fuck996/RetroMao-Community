# 1.1.0

## 中文

改为自定义启动入口插件，新增真实业务页面。选择平台并填写参数，默认预填 Azahar Plus；支持添加、编辑、删除和设为平台默认。需要复古猫 0.9.141 及模拟器授权。沿用原插件 ID 和默认入口 ID，同来源更新保留已保存参数。

## English

Adds a real business page for custom launch entries: choose a platform, edit Azahar Plus defaults, add/edit/delete entries and select a platform default. Requires host 0.9.141 and the Emulators grant. Retains plugin and seed IDs; same-source upgrades preserve saved parameters.

## 日本語

プラットフォームと起動パラメーターを設定する業務ページを追加しました。初期値は Azahar Plus で、追加・編集・削除・既定の選択に対応します。ホスト 0.9.141 とエミュレーター権限が必要です。プラグインと初期設定の ID を保持し、同じ配布元からの更新でも設定を維持します。
