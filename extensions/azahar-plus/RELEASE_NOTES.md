# Azahar Plus 1.0.0

## 中文

新增独立安装的 3DS 模拟器插件，声明 Azahar Plus 共存版与替换版的公开 URI 入口。需要宿主 0.9.136。启用后进入原模拟器选择；禁用或卸载后移除配置，保留用户选择。无页面、脚本或网络权限。当前为本地交付，尚未公开上架；真实设备进入游戏仍待验收。

## English

An installable 3DS emulator plugin declares public URI launch entries for both Azahar Plus Android variants. Requires host 0.9.136. Enable it to add profiles to the existing emulator selector; disabling or removing it withdraws those profiles while preserving saved selections. No pages, scripts or network access. Local delivery only; store publication and actual gameplay remain unverified.

## 日本語

Azahar Plus の共存版・置換版の公開 URI 起動設定を追加する、インストール可能な 3DS プラグインです。ホスト 0.9.136 が必要です。有効化すると既存のエミュレーター一覧に追加され、無効化や削除では設定を一覧から除き、保存済み選択は保持します。ページ、スクリプト、ネットワーク権限はありません。ローカル配布のみで、ストア公開と実機ゲーム起動は未検証です。
