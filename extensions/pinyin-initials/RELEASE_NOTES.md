# Pinyin initials search 1.0.0

## 中文

最低前端版本为复古猫 0.9.112。安装后进入插件的“配置”，启用并允许“增强搜索”，即可在游戏与应用的原搜索框中使用拼音首字母：`hdl` 查找“魂斗罗”，`jsq` 查找“计算器”。支持简繁中文、常见词组多音字以及混合英文和数字；专有名称仍可能存在读音差异。

使用固定版本 pinyin-pro 3.29.5 与 @pinyin-pro/data 1.3.1 繁体映射，离线运行，无联网、文件或资料写入权限。保留第三方 MIT 许可证及摘要，使用原脚本运行时与搜索范围。普通文字匹配立即显示，扩展准备与失败均有明确状态。无需重扫游戏库或同步 ROM。

真实插件脚本通过简繁体、多音字、混合名称和可复现打包检查；社区 26 项 Python、58 项 Node 测试通过。宿主的启用授权、错误传播和三比例搜索通过自动化检查。厂商掌机上的 Android JavaScript 隔离实例仍需实机验收。

## English

Requires RetroMao 0.9.112. After installing, open the plugin's configuration, enable it and grant search enhancement. Use the existing game/app search field: `hdl` finds 魂斗罗 and `jsq` finds 计算器. Simplified/traditional Chinese, contextual common polyphones, Latin text and numbers are supported; proper-name pronunciations can differ.

Bundles pinned pinyin-pro 3.29.5 and @pinyin-pro/data 1.3.1 traditional mappings for offline execution, with MIT notices and checksums. No network, file or metadata-write permission. The original runtime and search scope are retained. Literal matches appear immediately; preparation and failures are explicit. No library rescan or ROM synchronization is needed.

The actual script passes simplified/traditional, polyphone, mixed-name and reproducible-bundle checks. All 26 Python and 58 Node community tests pass. Host activation, grants, failure propagation and three aspect ratios pass automated checks. Android JavaScript-isolate behavior on vendor handhelds still requires device acceptance.

## 日本語

RetroMao 0.9.112 以上が必要です。インストール後、プラグインの設定で有効化し、検索拡張を許可してください。既存のゲーム・アプリ検索欄で `hdl` は「魂斗罗」、`jsq` は「计算器」を検索します。簡体字・繁体字、一般的な語句の多音字、英字・数字に対応します。固有名詞の読みには差が残る場合があります。

固定版 pinyin-pro 3.29.5 と @pinyin-pro/data 1.3.1 の繁体字対応表を同梱し、オフラインで動作します。MIT 表記と摘要を保持し、通信、ファイル、資料の書き込み権限は要求しません。従来のランタイムと検索範囲を使います。通常の文字一致は直ちに表示し、拡張の準備状態と失敗を明示します。再走査や ROM 同期は不要です。

実際のスクリプトで簡繁体、多音字、混在名、再現可能なバンドルを検査し、コミュニティの Python 26 件と Node 58 件が合格しました。ホストの有効化、許可、エラー通知、三つの画面比率も自動検証済みです。メーカー製携帯機上の Android JavaScript 隔離動作は実機確認が必要です。
