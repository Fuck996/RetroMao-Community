# RetroMao Community

复古猫社区扩展目录。应用从公开仓库的 `main/catalog.json` 读取列表，从 GitHub Release 下载 ZIP；用户也可以离线导入同一 ZIP。仓库只存放配置、素材和预览，不接收用户游戏、ROM、存档或网盘凭据。

## 投稿

平台包根目录放 `platform.json`；主题包根目录放 `theme.json`。先阅读 [扩展规范](EXTENSIONS.md)，用本机安装验证，再提交包含配置、素材、作者和 1280×720 主题预览图的 PR。维护者检查素材来源、包内路径、格式和三种窗口比例，合并后统一打包发布并更新 `catalog.json` 的字节数与 SHA-256。

`examples/` 是可重建的示例源文件。运行 `python tools/build_examples.py` 会生成示例图像、ZIP 和 `catalog.json`，并在 `dist/` 输出待发布的 ZIP。发布前需要确认生成内容的视觉效果和安装效果；此脚本不会自动上传 Release。

## 当前扩展边界

平台包提供机种身份、ROM 扩展名、介质类型、封面比例和图标，不修改复古猫的渲染器，也不内置模拟器或存档目录。主题包提供配色、布局、动效、背景、图标、字体及按机种替换的 GLB；模型仍沿用复古猫现有的透明图层、材质和动画管线。主题引用扩展机种时，必须先安装平台包。
