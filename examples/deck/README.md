## 中文

DECK 1.1.4 需要复古猫 Android 1.1.7 或更新版本，切换卡带或光盘时会播放短音效。已安装 DECK 时，在「设置 → 主题与显示 → 主题」打开 DECK 卡片并更新。首次安装可到「社区主题」下载并应用。Android 1.0.46～1.1.6 可手动导入 [DECK 1.1.3](https://github.com/Fuck996/RetroMao-Community/releases/tag/deck-1.1.3)。

最近游戏轮播、居中焦点、列表长度、资源状态角标、双屏上屏的模型来源、游戏库详情的无底板展台、靠左的顶部菜单和「查看更多游戏」的样式，都由主题包通过公开字段声明，应用不会替旧主题包补上这些效果。Android 1.0.43～1.0.45 可手动导入 DECK 1.1.2，1.0.39～1.0.42 可导入 DECK 1.1.1，更早的版本可导入 DECK 1.0.0。 [主题格式](../../docs/THEME_SHELL.md) · [DECK 1.1.2](https://github.com/Fuck996/RetroMao-Community/releases/tag/deck-1.1.2) · [DECK 1.1.1](https://github.com/Fuck996/RetroMao-Community/releases/tag/deck-1.1.1) · [DECK 1.0.0](https://github.com/Fuck996/RetroMao-Community/releases/tag/packs-2026-11-08)

## English

DECK 1.1.4 requires RetroMao for Android 1.1.7 or later and plays a short sound when switching cartridges or discs. Update from the DECK card in Settings → Theme & Display → Theme. For a first install, download and apply it from Community Themes. On Android 1.0.46 through 1.1.6, you can import [DECK 1.1.3](https://github.com/Fuck996/RetroMao-Community/releases/tag/deck-1.1.3) manually.

The theme pack uses public fields to declare its carousel, centred focus, list length, status badges, upper screen model source, the baseless library details stage, left-aligned top menu, and library shortcut style. The app does not add these effects to older theme packs. For Android 1.0.43 to 1.0.45, import DECK 1.1.2 manually; for 1.0.39 to 1.0.42, import DECK 1.1.1; for earlier versions, import DECK 1.0.0. ## 日本語

DECK 1.1.4 には Android 版 RetroMao 1.1.7 以降が必要です。カートリッジやディスクを切り替える際に短い効果音が鳴ります。「設定 → テーマと表示 → テーマ」の DECK カードから更新できます。初回は「コミュニティテーマ」からダウンロードして適用してください。Android 版 1.0.46～1.1.6 では [DECK 1.1.3](https://github.com/Fuck996/RetroMao-Community/releases/tag/deck-1.1.3) を手動で取り込めます。

モデルの横並び表示、中央のフォーカス、一覧の件数、状態バッジ、上画面のモデルの種類、ライブラリ詳細の台のない表示、左寄せの上部メニュー、ライブラリ入口の見た目は、テーマパックの公開フィールドで指定します。古いテーマパックにアプリがこれらの効果を追加することはありません。Android 1.0.43～1.0.45 では DECK 1.1.2、1.0.39～1.0.42 では DECK 1.1.1、それより前のバージョンでは DECK 1.0.0 を手動で取り込めます。 [テーマ形式](../../docs/THEME_SHELL.md) · [DECK 1.1.2](https://github.com/Fuck996/RetroMao-Community/releases/tag/deck-1.1.2) · [DECK 1.1.1](https://github.com/Fuck996/RetroMao-Community/releases/tag/deck-1.1.1) · [DECK 1.0.0](https://github.com/Fuck996/RetroMao-Community/releases/tag/packs-2026-11-08)
