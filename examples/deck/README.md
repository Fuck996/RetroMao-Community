# DECK

[中文](#中文) · [English](#english) · [日本語](#日本語)

## 中文

[DECK 1.0.0](https://github.com/Fuck996/RetroMao-Community/releases/tag/packs-2026-11-08) 适用于复古猫 Android 1.0.36 及以上。进入「设置 → 主题与显示 → 社区主题」，选择 DECK 并点击「下载并安装」，再到已安装主题中应用。

发布新版主题包后，支持卡片更新的复古猫版本会在「设置 → 主题与显示 → 主题」的 DECK 卡片上显示「更新到…」。旧安装没有版本记录时，可在卡片上点「安装社区版」。使用旧版复古猫也可在「社区主题」重新下载并安装。应用会先校验新包，再替换旧包，无需卸载。DECK 正在使用时会自动重新加载。

主题包提供配色、背景和 DECK 风格配置。最近游戏布局、末尾的「查看更多游戏」跳转、3DS 模式在游戏库内的行为，以及模型渲染性能由 Android 应用实现。要使用这些修正，需要安装包含修正的 APK，已有的 DECK 主题包可以继续使用。

## English

[DECK 1.0.0](https://github.com/Fuck996/RetroMao-Community/releases/tag/packs-2026-11-08) works with RetroMao for Android 1.0.36 or later. In Settings → Theme & Display → Community Themes, select DECK and choose Download and Install, then apply it from the installed themes list.

When a new pack is available, versions of RetroMao that support updates from the theme picker show an Update button on the DECK card under Settings → Theme & Display → Theme. If the installed pack has no version record, choose Install Community on the card. In older versions of RetroMao, download and install DECK again from Community Themes. RetroMao verifies the new pack before replacing the old one. If DECK is active, it reloads automatically.

The pack provides the colors, backgrounds and DECK style configuration. The Android app implements the Recent Games layout, the link at the end of the carousel, 3DS mode in the game library and model rendering. Install an APK containing those fixes to use them with the existing DECK theme pack.

## 日本語

[DECK 1.0.0](https://github.com/Fuck996/RetroMao-Community/releases/tag/packs-2026-11-08) は Android 版 RetroMao 1.0.36 以降に対応しています。「設定 → テーマと表示 → コミュニティテーマ」で DECK をダウンロードしてインストールし、インストール済みのテーマ一覧から適用してください。

テーマ一覧からの更新に対応した RetroMao では、新版が公開されると「設定 → テーマと表示 → テーマ」の DECK カードに更新ボタンが表示されます。インストール済みのパックにバージョンの記録がない場合は、カードからコミュニティ版をインストールしてください。旧版の RetroMao でも「コミュニティテーマ」から再インストールできます。アプリは新しいパックを検証してから旧版を置き換えます。DECK を使用中の場合は自動で再読み込みされます。

パックには配色、背景、DECK スタイルの設定が含まれます。最近遊んだゲームのレイアウト、一覧末尾からライブラリへの移動、ゲームライブラリの 3DS モード、モデルの描画は Android アプリ側の機能です。これらの修正を利用するには、修正を含む APK をインストールしてください。既存の DECK テーマパックは引き続き使用できます。
