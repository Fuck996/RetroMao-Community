# DECK

[中文](#中文) · [English](#english) · [日本語](#日本語)

## 中文

DECK 1.1.1 需要复古猫 Android 1.0.39 或更新版本。已安装 DECK 时，在「设置 → 主题与显示 → 主题」打开 DECK 卡片并更新。首次安装可到「社区主题」下载并应用。

最近游戏轮播、靠左的顶部菜单和「查看更多游戏」的样式由主题包通过公开字段声明。旧版 APK 可手动导入 DECK 1.0.0。 [主题格式](../../docs/THEME_SHELL.md) · [DECK 1.0.0](https://github.com/Fuck996/RetroMao-Community/releases/tag/packs-2026-11-08)

## English

DECK 1.1.1 requires RetroMao for Android 1.0.39 or later. Update from the DECK card in Settings → Theme & Display → Theme. For a first install, download and apply it from Community Themes.

The theme pack uses public fields to declare its carousel, left-aligned top menu, and library shortcut style. For older versions of RetroMao, import DECK 1.0.0 manually. [Theme format](../../docs/THEME_SHELL.md) · [DECK 1.0.0](https://github.com/Fuck996/RetroMao-Community/releases/tag/packs-2026-11-08)

## 日本語

DECK 1.1.1 には Android 版 RetroMao 1.0.39 以降が必要です。「設定 → テーマと表示 → テーマ」の DECK カードから更新できます。初回は「コミュニティテーマ」からダウンロードして適用してください。

モデルの横並び表示、左寄せの上部メニュー、ライブラリ入口の見た目はテーマパックの公開フィールドで指定します。旧版の RetroMao では DECK 1.0.0 を手動で取り込めます。 [テーマ形式](../../docs/THEME_SHELL.md) · [DECK 1.0.0](https://github.com/Fuck996/RetroMao-Community/releases/tag/packs-2026-11-08)
