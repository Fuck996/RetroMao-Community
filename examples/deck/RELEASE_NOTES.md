# DECK 1.1.0

[中文](#中文) · [English](#english) · [日本語](#日本語)

## 中文

主题包声明最近游戏首页、靠右的顶部菜单、紧凑的底部提示，以及与顶栏同样式的「查看更多游戏」入口。需要复古猫 Android 1.0.39。可从已安装主题卡片覆盖升级。

## English

The theme pack defines the Recent Games home, a right aligned top menu, compact footer hints, and a library shortcut that matches the top bar. Requires RetroMao for Android 1.0.39. Upgrade from the installed theme card.

## 日本語

最近遊んだゲームのホーム、右寄せの上部メニュー、簡潔な下部の操作案内、上部バーと同じ見た目のライブラリ入口をテーマパックで設定します。Android 版 RetroMao 1.0.39 が必要です。インストール済みのテーマカードから更新できます。
