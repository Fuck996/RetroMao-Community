# DECK 1.1.3

[中文](#中文) · [English](#english) · [日本語](#日本語)

## 中文

游戏库详情去掉模型下方的底板，模型直接立在地面上，带倒影和切换动作，与首页列表一致。需要复古猫 Android 1.0.46 或更新版本，可从已安装的 DECK 主题卡片直接更新；Android 1.0.43～1.0.45 继续使用 DECK 1.1.2。

## English

Library details no longer show a base under the model. The model stands directly on the floor with a reflection and a switch animation, matching the home list. Requires RetroMao for Android 1.0.46 or later. Update directly from the installed DECK theme card; Android 1.0.43 to 1.0.45 keep using DECK 1.1.2.

## 日本語

ライブラリの詳細でモデルの下の台をなくし、ホームの一覧と同じように、モデルが床に直接立ち、映り込みと切り替え時の動きが付きます。Android 版 RetroMao 1.0.46 以降が必要です。インストール済みの DECK テーマカードから直接更新できます。Android 1.0.43～1.0.45 では DECK 1.1.2 を引き続き使用できます。
