# DECK 1.1.1

[中文](#中文) · [English](#english) · [日本語](#日本語)

## 中文

顶部菜单恢复靠左，搜索回到右侧。需要复古猫 Android 1.0.39 或更新版本。可从已安装的 DECK 主题卡片直接更新。

## English

The top menu is back on the left, and search is back on the right. Requires RetroMao for Android 1.0.39 or later. Update directly from the installed DECK theme card.

## 日本語

上部メニューを左側に、検索を右側に戻しました。Android 版 RetroMao 1.0.39 以降が必要です。インストール済みの DECK テーマカードから直接更新できます。
