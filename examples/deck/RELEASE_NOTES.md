# DECK 1.1.2

[中文](#中文) · [English](#english) · [日本語](#日本語)

## 中文

改用主题格式 7。最近游戏列表的焦点停在中间，靠近两端时列表不再滚动，「查看更多游戏」留在最右侧；列表显示 20 个游戏，最近游戏在前，不足时按游戏库顺序补齐。卡片显示可下载、待上传等资源状态角标。双屏上屏在首页显示包装盒，在游戏库按「3D预览模型显示内容」设置切换介质或包装盒。游戏库详情去掉外层面板，模型只保留一层背景。需要复古猫 Android 1.0.43 或更新版本，可从已安装的 DECK 主题卡片直接更新；更早的版本继续使用 DECK 1.1.1。

## English

DECK now uses theme format 7. The recent games list keeps the focused game in the middle, stops scrolling near either end, and keeps "View more in your Library" on the far right. The list shows 20 games, with recent games first and the rest filled in library order. Cards show badges such as available to download or pending upload. On dual screens, the top screen shows the box on the home page and follows the "3D preview content" setting in the library. Library details drop the outer panel, so the model keeps a single background. Requires RetroMao for Android 1.0.43 or later. Update directly from the installed DECK theme card; earlier versions keep using DECK 1.1.1.

## 日本語

テーマ形式 7 に移行しました。最近のゲームの一覧は選択中のゲームを中央に保ち、両端に近づくとスクロールを止めて「ライブラリでさらに見る」を右端に残します。一覧には 20 本を表示し、最近のゲームを先頭に、足りない分はライブラリの順で補います。カードには、ダウンロード可能やアップロード待ちなどの状態バッジを表示します。2 画面では、上画面はホームでパッケージを表示し、ライブラリでは「3D プレビューの表示内容」の設定に従います。ライブラリの詳細は外側のパネルをなくし、モデルの背景を 1 層にしました。Android 版 RetroMao 1.0.43 以降が必要です。インストール済みの DECK テーマカードから直接更新できます。それより前のバージョンでは DECK 1.1.1 を引き続き使用できます。
