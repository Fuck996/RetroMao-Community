# Vita3K ROM 同步

作者：4NPC。插件 1.0.0，需要复古猫 0.9.98 或更新版本。

安装后在宿主的插件配置页选择 Vita3K 目录，启用并授权。目录中的 `fs`、`vita` 或 `files/fs`、`files/vita` 存储结构由插件规则自动定位，也可直接选择包含 `ux0` 的存储根。无需配置网盘；执行原系统 ROM 上传、下载或批量同步时自动带上对应游戏本体、补丁、DLC 和许可文件。

另一终端也需要安装、启用插件并选择自己的 Vita3K 目录。没有启用插件的终端保持原有标题索引、封面等资料同步，不会下载游戏本体，也不会删除云端扩展资源记录。

仅处理已纳入本次同步的 `.psvita` 游戏，不扫描或导入其他已安装游戏，不同步固件、配置、缓存和存档。存档继续使用宿主原有存档同步。任务进度、取消及恢复在宿主的传输任务卡片中操作，游戏启动不等待同步。

通用接口及维护约束见 [ROM 资源提供者](../../sdk/ROM_RESOURCES.md)。
