# Platform presentation example / 平台展示示例 / 機種表示の例

## 中文

这是原创虚构机种 Demo Console 的教学素材，不是任何真实日版机种的替代模型。图标和几何使用此示例的 [MIT 许可](LICENSE)。使用 tools/build_platform_example.py 可重建素材；用统一 CLI 检查和打包本目录即可得到含图标、包装与介质的完整离线平台包。没有 ROM、模拟器或启动项，也没有登记在线目录。[教程](../../docs/PLATFORM_GUIDE.md)。

## English

Original tutorial artwork for the fictional Demo Console, not a replacement for a real Japanese model. Icons and geometry use the example's [MIT license](LICENSE). Rebuild with tools/build_platform_example.py; use the unified CLI to check/pack this directory into a complete offline platform ZIP. No ROM, emulator, launcher or online catalog entry is included. [Guide](../../docs/PLATFORM_GUIDE.md).
