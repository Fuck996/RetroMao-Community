# MSX 1.1.0

## 中文

补齐日版包装/卡带 GLB、动态贴图和介质外壳材质；用与内置平台同源的正式图标替换旧演示图，Logo 可跟随主题色，用户主题仍可明确覆盖。最低宿主 1.0.32，平台 ID 保持 msx。通过应用内“设置 → 游戏库与文件夹 → 社区平台”下载或更新，无需单独导入 ZIP。

仓库校验、Python 33 项及 Node 63 项测试通过；模型可确定性重建，打包条目与源码逐字节一致。包装和卡带通过 Filament 1.77.3 桌面原生透明合成检查；主程序共享契约 5 项及相关平台/主题测试 12 项通过。真实模拟器启动和 Android GPU 验收尚未完成。旧 1.0.0 Release 资产不覆盖。

## English

Adds Japanese packaging/cartridge GLBs, dynamic artwork and shell materials. Replaces demo icons with credited art from the same sources as built-in platforms, adds theme-tinted logos and preserves explicit theme overrides. Minimum host 1.0.32; keeps msx identity. Download or update through Settings → Game library and folders → Community platforms without importing a separate ZIP.

Repository validation, 33 Python tests and 63 Node tests passed. Models rebuild deterministically and ZIP entries match source bytes. Both models passed the Filament 1.77.3 native desktop transparent-composition probe; 5 host shared-contract and 12 related platform/theme tests passed. Real emulator launch and Android GPU acceptance remain unverified. Existing 1.0.0 Release assets remain immutable.

## 日本語

日本版の箱/カートリッジ GLB、画像差替えと外装材質を追加。デモ用アイコンを内蔵機種と同じ出典の素材へ交換し、テーマ色ロゴとテーマの明示上書きに対応。最低ホスト 1.0.32、msx ID を維持します。設定 → ゲームライブラリとフォルダー → コミュニティ機種から取得・更新でき、ZIP の個別インポートは不要です。

リポジトリ検査、Python 33 件、Node 63 件のテストを通過。モデルの再生成は決定的で、ZIP 内の各項目はソースと一致します。両モデルは Filament 1.77.3 デスクトップ版のネイティブ透明合成プローブを通過し、ホスト共通契約 5 件と関連する機種/テーマのテスト 12 件も通過。実エミュレーター起動と Android GPU の実機確認は未完了です。既存の 1.0.0 アセットは上書きしません。
