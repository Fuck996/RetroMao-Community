# MSX 1.1.0

## 中文

补齐日版包装/卡带 GLB、动态贴图和介质外壳材质；用同源正式图标替换旧演示图，Logo 可跟随主题色。最低宿主 1.0.32，平台 ID 保持 msx。配置与网格检查、本地打包结果以本次开发记录为准；真实模拟器启动和 Android GPU 验收未宣称完成。旧 1.0.0 Release 资产不覆盖。

## English

Adds Japanese packaging/cartridge GLBs, dynamic artwork and shell materials. Replaces demo icons with credited production-source art and theme-tinted logo support. Minimum host 1.0.32; keeps msx identity. Configuration/mesh/local packaging results follow the development record; real emulator and Android GPU acceptance is not claimed. Existing 1.0.0 Release assets remain immutable.

## 日本語

日本版の箱/カートリッジ GLB、画像差替えと外装材質を追加。演示用アイコンを出典のある素材へ交換し、テーマ色ロゴに対応。最低ホスト 1.0.32、msx ID を維持します。設定/形状/ローカル ZIP の結果は開発記録を参照し、実エミュレーターと Android GPU の検証完了は主張しません。既存の 1.0.0 アセットは上書きしません。
