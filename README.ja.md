# RetroMao Community｜復古猫コミュニティ拡張

[中文](README.md) · [English](README.en.md) · **日本語**

このリポジトリでは、RetroMao の言語、プラットフォーム、テーマの拡張を管理しています。拡張に含まれるのは翻訳、設定、再配布可能な素材です。インストール時に ROM、セーブデータ、クラウドの認証情報をアップロードすることはありません。プラットフォームとテーマのオンラインインストールは **0.9.44 以降**、内蔵言語と追加言語のダウンロードは **0.9.87 以降**、複数リポジトリの設定は **0.9.88 以降**に対応しています。オンラインダウンロードには GitHub への接続が必要です。既存のゲームとインストール済み拡張はオフラインでも使えます。

現在ビルド済みのアプリバージョンは **0.9.94** です。[更新履歴（中国語）](CHANGELOG.md)を参照してください。スクリプトプラグインの実行基盤、バージョン管理、多言語対応、共通アイコンを提供し、共通のデータ API・同期処理・接続先設定を引き続き使用します。ストレージサービスをスクリプトから登録する機能は未公開です。現時点の役割分担は[同期サービス拡張ガイド（中国語）](SYNC_PROVIDERS.md)に記載しています。

## 公式・コミュニティのリポジトリを追加する

1. **設定のホーム画面右下**にある、アイコンのみのリポジトリボタンを押します。
2. 公開 GitHub リポジトリの URL を 1 行に 1 件ずつ入力します。例：`https://github.com/Fuck996/RetroMao-Community`。本リポジトリを Fork し、翻訳や拡張を独自に管理して、その URL をプレイヤーに共有できます。
3. 保存したリストは、言語、コミュニティテーマ、コミュニティプラットフォームで共用します。公式とコミュニティの両方を使う場合は、それぞれの行を残してください。空のリストを保存すると、リポジトリへのリクエストは行いません。
4. 各ダウンロード画面で拡張を選びます。同じ識別情報と内容を持つ項目は配布元を保持したまままとめ、内容が異なる項目は別々に表示します。名前だけで自動的に置き換えることはありません。言語のダウンロード画面には選択肢が表示され、リポジトリの URL はこの設定画面で入力します。

リポジトリ設定は拡張を探すためのもので、セーブ同期に使うクラウド接続とは別です。作者と配布元リポジトリは別々に表示します。Fork の管理者は元の作者のクレジットと素材のライセンス表記を保持してください。

## アプリからダウンロードしてインストール

### プラットフォームを追加する

1. **設定（设置）→ ゲームライブラリとフォルダー（游戏库与文件夹）→ コミュニティプラットフォーム（社区平台）**を開き、名前、作者、説明を確認します。
2. **ダウンロードしてインストール（下载并安装）**を選びます。ダウンロード、ファイルサイズと SHA-256 の検証、インストールが終わるまで待ちます。同じプラットフォームの更新版はこの一覧から再インストールできます。
3. **ゲームライブラリとフォルダー（游戏库与文件夹）**で、そのプラットフォームのローカル ROM フォルダーを追加します。パックにはゲームやエミュレーターは含まれません。ゲームの起動には端末内のエミュレーターを別途設定してください。

追加したプラットフォームは既存の機種選択、フォルダースキャン、ライブラリの処理を使います。インストールだけで端末全体をスキャンしたり、ROM をアップロードしたりしません。クラウドのリソース同期を使う場合は、従来どおり機種別の接続先とディレクトリを設定します。

### テーマを追加する

1. **設定（设置）→ テーマと表示（主题与显示）→ コミュニティテーマ（社区主题）**を開き、1280×720 のプレビュー画像、作者、説明を確認します。
2. **ダウンロードしてインストール（下载并安装）**を選びます。テーマは **インストール済みテーマ（已安装主题）**に追加されますが、現在のテーマは自動では切り替わりません。
3. 対象を選んで **テーマをプレビュー（预览主题）**し、実際の画面を確認してから **テーマを適用（应用主题）**します。拡張プラットフォームの素材を参照するテーマでは、先にそのプラットフォームをインストールしてください。

テーマには色、背景、動き、プラットフォームアイコン、フォント、パッケージ／メディアの GLB モデルを含められます。実際の内容は各パックの設定に従います。モデルの描画、マテリアル、アニメーションには RetroMao の既存の処理を使います。

### ZIP を手動でインストールする

オンラインで取得できない場合は、[公式サンプル Release](https://github.com/Fuck996/RetroMao-Community/releases/tag/packs-2026-10-06) の **Assets** から必要な `.zip` をダウンロードしてください。**解凍せずに**端末へコピーします。プラットフォームは **ゲームライブラリとフォルダー（游戏库与文件夹）→ プラットフォーム拡張パックをインポート（导入平台扩展包）**、テーマは **テーマと表示（主题与显示）→ テーマパックをインポート（导入主题包）**から選択します。手動インポートでもオンラインと同じ形式チェックとインストーラーを使い、GitHub への接続は不要です。

オンライン一覧の取得に失敗すると、前回正常に取得した一覧が表示される場合があります。表示されているだけでは、パックのダウンロードやインストールは完了していません。接続が戻ってから画面を開き直すか、ZIP を手動でインポートしてください。

## オンラインダウンロードの仕組み

1. アプリは公開の [`catalog.json`](catalog.json) を読み込みます。各項目には種類、バージョン、最低アプリバージョン、Release タグ、ファイル名、正確なバイト数、SHA-256 が記載され、テーマにはプレビュー画像のパスもあります。
2. 一覧から選ぶと、指定された **GitHub Release のアセット**である ZIP をダウンロードします。GitHub アカウントは必要ありません。
3. インストール前にバイト数と SHA-256 を検証します。一致しないファイルは拒否され、インストール済みの拡張を置き換えません。
4. 検証済み ZIP は手動インポートと共通のインストーラーに渡されます。設定形式、ZIP 内のパス、画像サイズ、容量制限を確認し、アプリの拡張ディレクトリに保存します。次回の起動でもそこから読み込みます。

カタログは一覧情報であり、インストールする本体は Release の ZIP です。プレビュー画像はインストールファイルではありません。ROM、セーブデータ、WebDAV のデータはこのリポジトリを経由しません。テーマ・プラットフォーム・言語パックではコードを実行しません。形式と制限は[拡張パック仕様](EXTENSIONS.md)を参照してください。

## 制作と投稿

スクリプトプラグインには、[SDK](sdk/README.md)、[ゲームメモのサンプル](examples/library-notes/)、メインメニューのプラグイン画面（インストール済み・ストア）があります。リポジトリ設定とダウンロード処理は既存のものを共用し、一覧には `plugins/index.json` を使用します。[お気に入り同期・最近遊んだゲームの履歴同期 1.0.2](https://github.com/Fuck996/RetroMao-Community/releases/tag/sync-examples-1.0.2) は公開済みで、0.9.94 以降が必要です。更新のルールは[バージョンと共通アイコンのガイド（中国語）](sdk/PLUGIN_VERSIONS.md)を参照してください。実行基盤と実際のクラウドストレージとの同期は、引き続き実機での検証が必要です。

- プラットフォーム ZIP のルートに `platform.json`、テーマ ZIP のルートに `theme.json` を置きます。オンラインテーマには同一規格の 1280×720 PNG/WebP プレビュー画像を用意します。
- [`examples/`](examples/) と[拡張パック仕様](EXTENSIONS.md)を参考にし、端末でのインポート、16:9／4:3／1:1、タッチ操作とコントローラー操作を確認してください。作者と素材の再配布ライセンスを明記し、ROM、ファームウェア、セーブデータ、秘密情報、アカウント情報は含めないでください。
- 設定、素材、プレビューを含む PR を送ります。レビュー後、メンテナーが ZIP を Release に公開し、**公開したアセット**のバイト数と SHA-256 を `catalog.json` に記録します。その後にオンライン一覧へ表示されます。

`python tools/build_examples.py` でサンプルを `dist/` に再生成できますが、Release の公開は行いません。[サンプル Release](https://github.com/Fuck996/RetroMao-Community/releases/tag/packs-2026-10-06) の説明は中国語・英語・日本語に対応しています。

プラットフォームパックは機種識別、ROM 拡張子、メディア形式、カバー比率、アイコンを定義します。エミュレーターやセーブディレクトリは提供しません。テーマは指定された外観素材を変更し、RetroMao のレンダラー自体は変更しません。

## 言語ファイルと翻訳への参加

言語ごとに 1 つの JSON ファイルを管理しています。翻訳の修正や新しい言語の追加を受け付けています。ファイル、投稿ルール、ダウンロード方法は [languages/](languages/README.md) を参照してください。現在の基準は **1233 件**です。簡体字中国語は `source`、英語・繁体字中国語・日本語は全件翻訳済みで、再確認用の `draft` として管理しています。

APK には簡体字中国語、繁体字中国語、英語、日本語が含まれます。初回はシステムの言語に合わせ、一致する言語がなければ簡体字中国語を表示します。**設定 → テーマと表示 → 言語**で言語を指定するか、システム設定に従う状態に戻せます。**言語をダウンロード**には、上記で設定したリポジトリの拡張が表示されます。オンラインでインストールできるのは、APK の文言基準に一致する完全な `reviewed` 拡張のみです。草稿は対象になりません。言語ファイルには専用のインストール処理があり、プラットフォームやテーマのインポート機能は使いません。
